# 걸어올레 · 걸어 올래?

제주 우리 동네 생활권 진단 AI Agent. 질문 한 줄로 동네에서 생활 시설까지 걷는 시간과 거리를 알려 줍니다.

제주 43개 읍면동에서 걸어서 약국, 의원, 버스정류장 같은 생활 시설에 얼마나 닿는지 질문 하나로 분석합니다.
보행자 유형(일반 성인, 어르신, 보조기구 사용 어르신, 아이 동반 보호자)마다 걷는 속도를 다르게 적용합니다.

## 1. 실행 (센터 PC)

1. Python 3.10 이상을 설치합니다. 설치할 때 "Add python.exe to PATH"를 체크합니다.
2. 이 폴더의 `run.bat`을 더블클릭합니다.
3. 처음 한 번은 패키지 설치로 3~5분 걸립니다. 끝나면 브라우저에 화면이 열립니다.
4. 종료하려면 검은 창을 닫습니다.

LLM 없이도 모든 기능이 동작합니다. LLM은 규칙으로 알아듣지 못한 질문의 해석과 "AI 해설 보기"에만 씁니다.

### 선택: 로컬 LLM (Qwen3.5-4B)

1. https://ollama.com 에서 Windows용 Ollama를 설치합니다.
2. 명령 창에서 `ollama pull qwen3.5:4b`를 실행합니다. 약 2.7GB입니다.
3. `run.bat`을 다시 실행하면 왼쪽 위에 "LLM: Qwen (로컬)"이 표시됩니다.

### 선택: Gemini API (평가용)

Ollama가 없을 때 `.env` 파일에 `GEMINI_API_KEY=키`를 넣으면 Gemini를 씁니다. 키는 https://aistudio.google.com 에서 무료로 발급합니다.

## 2. 사용법

- 첫 화면에서 성인, 어르신, 보행보조, 아이 동반 중 누구 걸음으로 볼지 고릅니다.
- 가운데 입력창에 질문합니다. 무엇을 물을 수 있는지는 아래 표를 보세요.
- 결과 화면 왼쪽 카드에 핵심 숫자가, 오른쪽에 지도가 나옵니다.
- 카드 아래 버튼("어르신 걸음으로 하면?", "10분이면?" 등)을 누르면 앞 조건을 이어받아 다시 계산합니다. 입력창에 직접 이어서 물어도 됩니다.
- 오른쪽 위에서 걸음 기준을 바꾸면 같은 질문을 그 기준으로 다시 계산합니다.
- "직접 고르기"를 펼치면 질문 없이 조건을 골라 볼 수 있습니다.
- "이렇게 계산했어요"에서 어떤 데이터를 몇 건 쓰고 무엇을 뺐는지 확인합니다.
- 지도 아래 "표로 보기", "표 내려받기 (CSV)"로 숫자를 받습니다.

할 수 있는 분석

| 종류 | 예시 질문 |
|---|---|
| 우리 동네에서 몇 분 | 애월읍에서 약국까지 걸어서 얼마나 걸려 |
| 가장 먼 동네 | 아이랑 소아과 가기 가장 불편한 동네 3곳 |
| 가까운 시설 찾기 | 표선면 세화리 가까운 의원 |
| 새 시설이 생기면 | 애월읍에 보건진료소가 새로 생기면 어디가 좋아 |
| 예전과 비교 (약국·병의원만) | 대정읍 약국 예전보다 멀어졌어? |

볼 수 있는 시설: 약국, 의원, 병원급, 소아청소년과, 치과, 보건기관, 치매안심센터, 도서관(새마을문고 포함), 버스정류소, 박물관·미술관

## 3. 데이터 갱신 (선택)

제출물에는 2026-11-15에 수집·전처리한 결과(`data/`)가 들어 있어 바로 실행됩니다. 새로 수집하려면 아래 순서로 실행합니다.

1. 제주데이터허브(jejudatahub.net)에 가입하고, 마이페이지 → 프로젝트 관리 → 프로젝트 만들기.
2. `collect/apis.json`에 있는 12개 데이터의 상세페이지에서 "프로젝트 담기".
3. 카카오 Developers에서 앱을 만들고 카카오맵 사용을 켠 뒤 REST API 키를 받습니다.
4. `.env.example`을 `.env`로 복사하고 `JEJU_PROJECT_KEY`(제주데이터허브 프로젝트키)와 `KAKAO_REST_KEY`를 넣습니다. 프로젝트키를 비워 두면 collect.py가 실행 중에 물어봅니다.
5. https://download.geofabrik.de/asia/south-korea-latest.osm.pbf 를 `data_ext/`에 받습니다.
6. 명령 창에서 차례로 실행합니다.

```
pip install -r requirements-prep.txt osmium
python collect.py
python -m prep.facilities
python -m prep.geocode
python -m prep.osm_pbf
python -m prep.grid
python -m prep.population
python -m prep.buildings
python -m prep.stops
python -m prep.distances
python -m prep.hero_dots
python -m prep.emd_office
```

## 4. 폴더 구조

```
app/        화면(ui.py), Agent 흐름(agent.py), 분석 도구(analysis.py), 질문 해석(query.py, llm.py)
prep/       전처리 스크립트
collect.py  제주데이터허브 API 수집 (apis.json)
data_raw/   API 원본
data/       전처리 결과 (실행에 필요)
data_ext/   읍면동 경계, 보행 도로망
docs/       설계, 계획, 검증 기록, 데이터 활용 명세(data_spec.md), 결과 설명자료(result_summary.md)
tests/      pytest 72개, 질문 평가 세트
```

## 6. 오픈소스와 AI 사용 내역

- 오픈소스: streamlit, folium, pandas, numpy, networkx, scipy, pyproj, shapely, requests, osmium, osmnx
- 글꼴: Pretendard (길형진, SIL Open Font License 1.1). `app/static/`에 원본 라이선스와 함께 넣었습니다.
- 실행 중 AI: Qwen3.5-4B (Apache 2.0, Ollama 로컬 실행), 선택적으로 Gemini API
- 개발 중 AI: Anthropic Claude로 설계, 코드 작성, 테스트, 문서 초안 작성을 보조받음

## 7. 오류와 제약

- 경사와 계단은 반영하지 않습니다.
- 진료·영업 시간, 휴무일은 데이터에 없습니다.
- 결과는 모두 걷는 시간(분)과 거리(m)로 보여 줍니다. 동네 중심은 읍면동 사무소(주민센터) 위치이며 OpenStreetMap에서 가져왔습니다. 추자면은 위치가 없어 버스 정류소가 가장 촘촘한 곳을 씁니다.
- 8km 넘게 걸어야 하면 '걸어서 가기 어려움'으로 표시합니다.
- 예전과 비교는 개·폐업일이 있는 약국·병의원만 됩니다.
- 약국·병의원은 2025년 9월, 박물관·미술관은 2025년 9월, 도서관·새마을문고·치매안심센터는 2021년 11월 기준입니다.
- 화면이 열리지 않으면 검은 창의 마지막 오류 줄을 확인하고, `.venv` 폴더를 지운 뒤 다시 실행합니다.

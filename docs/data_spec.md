## 3. 전처리와 분석 흐름

1. `collect.py`: API 12종을 쪽 단위로 받아 `data_raw/`에 저장. 502 오류는 다시 시도.
2. `prep.facilities`: 시설 종류를 나누고 영업 여부, 인허가일, 폐업일을 정리. 6,693건.
3. `prep.geocode`: 주소를 좌표로 변환. 2,212건 중 2,186건 성공, 26건 실패 (목록은 `data/geocode_report.json`).
4. `prep.osm_pbf`: OSM에서 걸을 수 있는 길만 골라 도로망 406,751개 지점을 만든다.
5. `prep.grid`: 읍면동마다 250m 격자, 17,134개.
6. `prep.distances`: 시설 10종 × 현재와 2019~2025년 말, 격자마다 가장 가까운 시설까지 거리. 1,370,720행.
7. `prep.hero_dots`, `prep.emd_office`: 첫 화면 배경과 읍면동 사무소 위치.
8. 실행 중: 질문 해석 → 분석 도구 → 시설에서 동시에 출발하는 최단거리(8km까지) → 걸음 속도로 나눠 분으로 변환.

# 결과 설명자료: 걸어올레 · 걸어 올래?

서비스명 걸어올레는 "걸어 올래?"라는 권유와 제주어 올레(큰길에서 집까지 이어진 골목)를 합친 이름이다.

## 1. 문제 정의

제주데이터허브의 약국·병의원·도서관 정보는 주소 목록이다. 도민이 "우리 동네에서 약국까지 걸어서 몇 분인가"를 알려면 주소를 지도에 올리고 길을 따라 거리를 재야 한다. 지도 앱은 한 지점에서 한 곳까지만 알려 주고, 어르신이나 아이와 걷는 보호자의 느린 걸음은 반영하지 않는다.

## 2. Agent 구조

1. 질문 해석: 규칙 사전으로 동네, 시설, 걸음 기준, 질문 유형을 읽는다. 규칙이 실패하면 로컬 Qwen3.5-4B에 넘긴다.
2. 조건 이어받기: "어르신 걸음으로 하면?"처럼 이어 물으면 앞 질문의 동네와 시설을 그대로 쓴다.
3. 도구 실행: 동네 시간, 가까운 시설, 먼 동네, 새 시설 시뮬레이션, 예전과 비교.
4. 결과 구성: 시간 카드, 지도, 목록, 표, CSV.
5. 설명: 계산 과정과 출처를 붙인다. Qwen이 풀어 쓴 해설에 숫자가 섞이면 버린다.

모호한 질문은 되묻는다 ("병원"은 의원인지 병원급인지). 데이터에 없는 시설은 없다고 답한다.

## 3. 주요 기능

| 질문 유형 | 예시 | 결과 |
|---|---|---|
| 우리 동네에서 몇 분 | 대정읍 약국까지 걸어서 얼마나 걸려? | 읍면동 사무소에서 가까운 약국까지 분·m, 동네 격자 지도 |
| 가장 가까운 시설 | 한림읍 어르신 가장 가까운 의원 | 가까운 순서 5곳 |
| 가장 먼 동네 | 아이랑 소아과 가기 가장 불편한 동네 3곳 | 읍면동 사무소 기준 오래 걸리는 순서 |
| 새 시설이 생기면 | 애월읍에 약국이 새로 생기면? | 후보 위치 3곳과 줄어드는 시간 |
| 예전과 비교 | 대정읍 약국 예전보다 멀어졌어? | 2019~2024년 말과 비교 (약국·병의원만) |

걸음 기준: 일반 성인 1.00m/s, 어르신 0.85m/s, 보조기구 사용 어르신 0.73m/s, 아이 동반 보호자 0.80m/s(가정).

## 4. 실행 결과 예시

대정읍 약국 (일반 성인)
- 대정읍사무소에서 가장 가까운 약국: 메디팜현대약국, 10분, 616m
- 어르신 걸음이면 12분
- 대정읍 안 약국 14곳은 거의 하모리에 있다. 읍의 나머지 대부분은 가장 가까운 약국까지 30분이 넘는다.

제주 전체, 읍면동 사무소에서 약국까지 30분 넘는 곳: 우도면(8km 안에 없음), 대천동 45분, 예래동 44분, 영천동 38분.

## 5. 검증 방법과 한계

자세한 기록은 `docs/validation.md`.

- 질문 해석: 개발자 작성 30문항 30/30. 외부 작성 범위 밖 10문항 10/10 거절. 외부 작성 범위 안 10문항은 수정 전 1개, 수정 후 9개 맞힘 (같은 문항이라 일반화 성능이 아니다).
- 걷는 거리: 카카오맵 도보 길찾기와 19쌍 비교. 평균 절대 오차 108m, 오차율 중앙값 5.5%, 상관계수 0.957.
- 자동 테스트 87개.

한계
- 경사, 계단, 신호 대기를 반영하지 않는다.
- 진료·영업 시간이 데이터에 없다.
- 아이 동반 속도는 측정 연구가 없어 가정했다.
- 동네 중심은 읍면동 사무소다. 추자면은 위치가 없어 버스 정류소가 가장 촘촘한 곳을 쓴다.
- 지도의 격자 점에는 사람이 살지 않는 산간 도로도 들어 있다.
- 도서관·새마을문고·치매안심센터는 2021년 11월 기준 데이터다.

## 6. 센터 활용 방안

- 센터를 찾은 도민이 자기 동네와 가족의 걸음으로 직접 확인한다.
- 결과 표를 CSV로 받아 마을 회의나 주민자치 자료로 쓴다.
- 새 시설 후보 위치를 넣어 걷는 시간이 어떻게 바뀌는지 본다.
- 실행: `run.bat` 더블클릭. 계산은 CPU만 쓰고, Qwen이 없어도 모든 기능이 동작한다.

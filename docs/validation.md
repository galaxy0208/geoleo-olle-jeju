## 1. 질문 해석

| 평가 세트 | 문항 | 결과 | 비고 |
|---|---|---|---|
| 개발자 작성 (tests/eval_questions.csv) | 30 | 30/30 완전 일치, 평균 0.17초 | 규칙을 만든 사람이 쓴 질문이라 점수가 후하다 |
| 외부 작성, 범위 밖 (holdout 1~10) | 10 | 10/10 거절 | 지원금·복지 상담 질문. 잘못된 분석을 내놓은 경우 없음 |
| 외부 작성, 범위 안 (holdout 11~20), 수정 전 | 10 | 완전 1, 부분 5, 틀림 4 | docs/holdout_result_before.md |
| 같은 10문항, 수정 후 | 10 | 완전 9, 부분 1 | 같은 문항으로 고쳤으므로 일반화 성능이 아니다 |

수정 전 틀린 유형과 고친 내용
- 시설 두 개를 함께 물음 → 시설마다 따로 계산해 이어서 보여줌
- "제주시 안에서", "서귀포 동네 중" → 행정시 범위로 좁힘
- "거동이 불편하신 분" → 보조기구 사용 어르신으로 해석
- "예전이랑 비교" → 2019년 말과 비교
- "책 빌려볼 수 있는 데" → 공공도서관
- "오늘 문 연 곳" → 영업시간 데이터가 없다고 안내하고 걸어서 닿는 곳만 제시

남은 한계
- 16번: "병원이나 버스정류장"에서 "병원"을 따로 묻지 않고 정류장만 답함. "병원"만 단독으로 쓰면 의원과 병원급 중 무엇인지 되묻는다.
- 규칙에 없는 표현은 로컬 LLM(Qwen3.5-4B)으로 넘기지만, 사용자 PC에서 질문당 14~21초 걸렸다.

## 2. LLM 응답 시간 (사용자 PC, Ollama qwen3.5:4b)

| 질문 | 시간 |
|---|---|
| 한림읍 어르신 걸어서 약국 갈 수 있는 비율 | 20.9초 |
| 아이랑 10분 안에 소아과 못 가는 동네 3곳 | 16.1초 |
| 애월읍에 보건진료소가 새로 생기면 어디가 좋아 | 14.0초 |

이 결과로 규칙 해석을 먼저 쓰고, 규칙이 실패할 때만 LLM을 부르도록 바꿨다. LLM은 질문의 읍면동 목록을 통째로 베끼는 오류도 보였다(2번 질문). 지금은 질문에 실제로 나온 이름만 남긴다.

## 3. 보행 거리

정류소 → 시설 20쌍을 카카오맵 도보 길찾기(최단거리)와 비교했다. 표본은 이용객 50명 이상 정류소에서 300m~2km 떨어진 시설을 읍면동마다 하나씩 무작위로 골랐다. 원자료는 docs/validation_pairs.csv.

| 지표 | 값 |
|---|---|
| 비교한 쌍 | 19 (1쌍 제외) |
| 평균 절대 오차 | 108m |
| 절대 오차율 중앙값 | 5.5% |
| 절대 오차율 평균 | 14.2% |
| 오차율 15% 이내 | 15/19 |
| 상관계수 | 0.957 |

- 7번 제외: 같은 이름의 치과가 제주시와 서귀포시에 하나씩 있는데, 검증용 링크가 제주시 쪽을 가리켜 35.3km가 나왔다. 계산은 서귀포시 쪽으로 했으므로 링크 생성 오류다.
- 11번(효돈중학교 → 효돈중앙의원): 계산 615m, 지도 271m. 지도 서비스가 쓰는 골목길이 OSM에 없을 가능성이 크다.
- 5번은 계산이 28% 길고 18번은 26% 짧다. 큰 오차는 양쪽으로 다 나와서 한쪽으로 치우친 경향은 없다.
